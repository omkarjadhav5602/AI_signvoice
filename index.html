How it works

Signvoice AI explores real-time Indian Sign Language to text and speech, using computer vision and temporal deep learning.

Proposed pipeline

  1. Capture gesture frames from a smartphone camera.
  2. MediaPipe extracts 21 hand landmarks (X, Y, Z; 63 features per hand).
  3. An LSTM or GRU learns motion across frame sequences.
  4. Segment signs, combine words into sentences, and use text-to-speech.
  5. Deploy a lightweight model in a Flutter Android app with TensorFlow Lite.

Project roadmap

Demo → collect and label ISL sequences → train and evaluate the model → TensorFlow Lite → Android app.

The current prototype does not yet include trained recognition.
